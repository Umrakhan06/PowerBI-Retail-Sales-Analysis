Power BI Retail Sales Analysis Dashboard

📊 Project Overview

This project is a Power BI Retail Sales Analysis Dashboard created
to practice and demonstrate advanced Power BI visuals, data analysis,
and filtering techniques using the provided retail sales dataset.

The dashboard currently includes Q1--Q13 of the assigned tasks.

🛠️ Tools & Technologies

Power BI Desktop

DAX for measures

Retail sales dataset

📌 Visuals & Analysis

The dashboard includes:

Card Visual -- Total Sales

Donut Chart -- Sales by Ship Mode

Line Chart -- Monthly Sales Trend

Clustered Bar Chart -- Sales by Category

Matrix -- Sales by Month and Category

Decomposition Tree -- Sales analysis by Region, Category and
Sub-Category

Scatter Chart -- Discount vs Profit by Sub-Category with a
Furniture category filter

Funnel Chart -- Number of Orders by Customer Segment

Waterfall Chart -- Profit contribution across Categories and
Sub-Categories

Page-Level Filter -- Asia Pacific Market

Report-Level Filter -- Consumer Segment

Top N Filter -- Top 5 Sub-Categories by Sales

KPI Visual -- Total Sales compared with Total Profit

🔍 Key Features

Interactive Power BI visuals

Monthly sales trend analysis

Category and sub-category analysis

Ship Mode sales analysis

Profit contribution analysis

Discount vs Profit analysis

Page-level and report-level filters

Top 5 sub-category analysis

KPI comparison of Sales and Profit

🎯 Project Objective

The objective of this project is to develop practical skills in:

Creating and formatting Power BI visuals

Using appropriate fields and aggregations

Applying visual-level, page-level, and report-level filters

Creating and using DAX measures

Analysing sales and profit trends

Presenting business data in an interactive dashboard
